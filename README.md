# AVIRA BY SASSUI

Luxury fragrance website: perfumes, fragrance mists, wax balms and bundle packs.

Built with plain HTML, CSS and JavaScript (no build step).

## Features
- Collections and Bundle Packs open from the menu
- Shopping bag with quantity controls and "Copy Order Summary"
- Currency options: PKR, USD, EUR, JPY, SAR, QAR, AED
- Product search and video reels

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the folder to any static host (for example Netlify).

## Updating exchange rates
Edit the `RATES` object at the top of the currency section in `js/script.js`.
